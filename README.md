# Solkie OS v1.0
### A Developer-Centric Ubuntu Remix

**Solkie OS** is a hobbyist project providing a pre-configured, "ready-to-code" environment built upon **Ubuntu 24.04 LTS (Noble Numbat)**. It aims to provide a streamlined workstation by removing standard desktop bloat and pre-installing essential development runtimes.

---

## ✨ Features

* **The Solkie Stack:** Pre-configured with Python 3, Django, Rust, Java (JDK), and MongoDB.
* **Privacy First:** Replaced VS Code with **VSCodium** (Solkie Edition) to remove proprietary telemetry.
* **Native Performance:** Firefox is provided via the Mozilla PPA (Debian package) rather than Snap for faster startup times.
* **Lightweight:** Removed heavy suites like Thunderbird and LibreOffice to save disk space and resources.
* **Custom Identity:** Includes custom Solkie aesthetics while respecting the underlying Ubuntu base.

## 🛠️ Installation & Usage

### Option 1: Download the ISO (Community Build)
You can download the current build of the Solkie OS ISO here:
👉 **[Download Solkie OS v1.0](https://drive.google.com/file/d/1feCy96xkDLpCPU4yAK2wovpzy1SV8OGI/view?usp=sharing)**

> **Note:** As this is a personal remix, this ISO is provided for testing and educational purposes. Always verify the integrity of downloaded files.

### Option 2: Build Your Own (Recommended)
To ensure transparency, you can recreate this OS in about 15 minutes using **Cubic** (Custom Ubuntu ISO Creator):

1.  Download the official [Ubuntu 24.04 Desktop ISO](https://ubuntu.com/download/desktop).
2.  Load the ISO into Cubic.
3.  When prompted with the terminal, execute the commands found in `solkie_build.sh` in this repository.
4.  Generate your custom ISO.
