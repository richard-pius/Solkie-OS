# Solkie OS v1.0

**Solkie OS** is a hobbyist, developer-centric Linux environment built on the rock-solid foundation of **Ubuntu 24.04 (Noble Numbat)**. It is designed to be a "ready-to-code" workstation that removes the bloat and adds the essential tools every modern dev needs.

---

## ✨ Features
- **The Solkie Stack:** Pre-configured with Python 3, Django, Rust, Java (JDK), and MongoDB.
- **Privacy First:** Replaced VS Code with **VSCodium** (Solkie Edition) to strip out Microsoft telemetry.
- **Native Experience:** Firefox is installed via the Mozilla PPA (no Snaps!) for maximum speed.
- **Lean & Mean:** Removed Thunderbird and LibreOffice to keep the system lightweight.
- **Custom Branding:** Features the signature Solkie wallpaper and system identity.

---

## 🛠️ Build Your Own Solkie OS
Since this is a hobby project, I am sharing the **Build Script** rather than the ISO binary. You can recreate Solkie OS in about 15 minutes using **Cubic** (Custom Ubuntu ISO Creator).

### 📋 Prerequisites
1. Install [Cubic](https://github.com/PJ-Singh-001/Cubic) on your host Linux machine.
2. Download the official **Ubuntu 24.04 Desktop ISO**.

### 🚀 The Build Process
1. Load the Ubuntu ISO into Cubic.
2. When you reach the terminal, copy and paste the commands from the `solkie_build.sh` script found in this repository.
3. Once the script finishes, click **Next** and **Generate** your ISO!
